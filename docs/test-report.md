## 시각 검토 (역할 C)
- 독립 리뷰어로 codex를 쓰려 했으나 사용량 한도(오후 7:35 KST 재개)로 **독립 시각 리뷰는 미실시**.
  아래는 구현과 같은 에이전트의 별도 검토 패스이며 독립 검토가 아니다.
- 확인함: 두 캐릭터의 same_phase_sheet(6위상 × 8방향) — 방향 간 크기·높이·동작 상태 일치, 얼굴/소품 변화 없음, 왕 발 고정, 활 형태 유지.
- 확인함(이전 단계): bunny SE 확대·느린 GIF, 왕 게임 크기 strip(8px에서 호흡 인지 가능).
- **needs_review로 남김**
  - bunny NW: 왼쪽 가장자리에 움직이지 않는 작은 날개 조각.
  - bunny NW/NE: 아래 발/다리 일부가 날개 마스크로 분류(spread 시 함께 움직일 수 있음).
  - bunny SE: 귀 뒤 먼 쪽 날개 조각이 날개 마스크에 포함 — 의도와 다를 수 있음.
  - king SE: 활 마스크 부분적(6134px) → 활 일부가 호흡 시 미세 늘어남 가능.
- 정상 속도 확인은 GIF(근사 타이밍)로만 함. 엔진 실속도 재생은 하지 않음(Godot 작업 제외 요청).
